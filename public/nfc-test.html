NFC 태그 인식 테스트 (테스트용)

NFC 리더기를 사기 전에 갤럭시 S24 의 NFC 로 태그를 읽어 보는 화면이에요. 태그를 읽으면 페이지를 옮기지 않고 오른쪽에 제품 정보 패널이 열려요. 실제 표시는 진짜 태그를 읽은 결과이고, 시뮬레이션 표시는 버튼으로 흉내 낸 결과예요. 카드 번호는 저장하지 않고(새로 고치면 사라짐), 다른 기기로 보낼 때는 가린 번호와 지문(해시)만 보내요.

입력 경로

① 이 기기 NFC 실제

갤럭시 S24 의 Chrome 에서 이 화면을 열었을 때 쓰는 방식이에요 (Web NFC, https 필요).

② 갤럭시 S24 연결 실제

PC·iPad 에 이 화면을 열어 두고, 휴대폰을 NFC 리더기로 써요. 서버 실행(npm start)이 필요하고, 휴대폰 쪽 Web NFC 때문에 https 주소(cloudflared 터널)로 열어야 해요.

③ 외부 리더기 실제

USB·블루투스 NFC 리더기(키보드 모드)를 연결하면 따로 시작하지 않아도 태그 입력을 받아요. 리더기를 사면 이 경로로 시험해요.

④ 시뮬레이션 시뮬레이션

실제 태그 없이 같은 처리 길을 지나 봐요. 결과에 '시뮬레이션'으로 표시돼요.

임시 연결 (이 화면에서만, 저장하지 않음)

교통카드·출입카드처럼 번호(지문)만 읽히는 카드를 시험용 제품에 잠깐 연결해요. 카드 번호를 제품 ID 로 쓰지 않고, 이 화면을 새로 고치면 사라져요.
