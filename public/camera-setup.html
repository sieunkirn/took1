USB 직접 연결 (툭 앱)

갤탭은 USB 웹캠을 Android 카메라로 등록하지 않아서 Chrome 으로는 웹캠이 안 보여요. 툭 앱(APK)은 USB 로 웹캠에 직접 붙어서 영상을 받아요. 웹캠을 꽂으면 뜨는 창에서 '툭'·'항상'을 고르면 다음부터 묻지 않아요

갤탭에서 안 잡힐 때

  1. Chrome 이 아니라 툭 앱(APK)으로 열어야 USB 웹캠에 직접 붙어요 (Chrome 은 갤탭이 등록한 카메라만 봐요)
  2. 웹캠을 USB-C(OTG) 젠더나 전원을 꽂은 USB 허브로 연결하고, 꽂은 뒤 '카메라 다시 찾기'
  3. 목록에 '외장'이 안 보이면 웹캠을 뽑았다 다시 꽂거나, 다른 USB 포트·케이블로 바꿔 보기
  4. '사용 중'이라고 나오면 갤탭의 카메라 앱·다른 Chrome 탭을 모두 닫기
  5. 권한이 '거부'면 Chrome 주소창 왼쪽 자물쇠 → 권한 → 카메라 허용, 또는 갤탭 설정 → 애플리케이션 → Chrome → 권한 → 카메라 허용
  6. 터치 필름 USB와 같이 꽂았을 때만 안 되면 해상도를 640×480, 프레임을 15로
