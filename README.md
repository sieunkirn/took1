# took(툭)

매장에 두는 **스마트미러 립 키오스크**입니다. 손님이 거울 앞에 서면 카메라가 입술을 찾아 립 색을 바로 발라 보여 주고, 들고 온 제품(NFC 태그)이나 색 다이얼로 색을 고른 뒤 호수를 정해 가져가게 합니다.

- 기기: 노트북(Windows + Chrome)을 세로 모니터에 연결한 스마트미러. USB 웹캠(**USB 2.0 Camera**, USB VID 0C49 / PID 636F), 블루투스 NFC 리더기(키보드 모드). 설치형 프로그램 없이 브라우저만으로 돈다
- 화면: 세로 **900×1440**(5:8) 하나를 기준으로 그린다
- 언어: 한국어 / 영어 (서비스 전체)

프로젝트 규칙(디자인·개발·데이터 원칙, 작업 방식)은 [CLAUDE.md](CLAUDE.md) 에 있습니다.

## 손님 흐름

```
시작 화면(영상) ──터치──▶ 거울 ──┬─ ① 제품 올리기: NFC 태그
                                 └─ ② 색 돌려 보기: 원형 다이얼
                                        │
                              입술에 발라 보기 → 호수 고르기   (가져가기는 2026-11-20부터 꺼 둠)
```

- 거울 첫 화면은 **맨입술**이다 (아래 '거울' 절)
- 손이 자주 가는 곳(문구·색·크기·시간)을 직접 고칠 때는 [docs/직접-고치기-안내서.md](docs/직접-고치기-안내서.md)

### 시작 화면 (`index.html`, `js/home.js`)
- 배경 영상(`videos/home.mp4`) + 가운데 TOOK 로고 + 'Tap The Screen'. 화면 아무 곳이나 누르면 **바로 거울로** 간다 (2026-11-24, 예전엔 4번 버튼 화면)
- 순서: 제품 장면(영상 3.45~4.95초, 1.5초) + 로고 → 입술 장면(1.5초) + 로고 → **3초째** 'Tap The Screen' (2026-11-20). 이후 입술 장면만 되풀이
- 언어(한/영) 버튼은 시작 화면에만 있다
- 4번 화면(2026-11-21, Figma GP `1667:704`, 2026-11-24부터 평소 흐름에서 빠짐 · `?step=4` 로만 보임): 검정 바탕, 로고가 위(y 380.77)로 올라가고 알약 버튼 2개가 세로로. 1 스캔 = 거울(`palette.html`) · 2 NFC = 거울에서 '제품을 태그해보세요' 안내 후 리더기 기다리기. 아이콘은 `images/home-menu/`. 시작 화면은 요청 없이 바꾸지 않는다
- 시작 화면을 **5초 길게 누르면** 관리자 화면(`admin.html`)이 열린다

### 거울 (`palette.html`, Find Your Color)
- **거울 첫 화면 = 맨입술** (2026-11-24, 주요 규칙): 시작 화면에서 거울로 처음 들어왔을 때, 그리고 초기화(자동 초기화·집 버튼·로고) 뒤에 들어왔을 때는 **아무 제품·색도 입히지 않은 상태**여야 한다. 다이얼을 돌리거나 제품을 발라 보거나 NFC 로 제품을 올린 뒤부터 색이 입혀진다. 판단은 고른 기록(`store` 의 `fcSel`, sessionStorage)이 없으면 '처음'이다(`js/palette.js` `bareStart`). 색이 없을 때(`lip.hex = null`) 입술 그리기(`js/lip-engine.js` `applyLipColor`)는 아무것도 칠하지 않는다
- 카메라가 화면 전체를 채우고, 얼굴을 따라 괄호 4개가 감싼다. 입술에는 고른 색이 실시간으로 칠해진다
- **다이얼**: 원형 그래프 28칸(빨강·핑크·오렌지·누드 × 7칸)이 손가락을 따라 돌고, 놓으면 칸에 멈춘다. 색은 모두 립 DB 의 실제 색
- **질감 동그라미**: matte · glossy · satin · sheer · shimmer. 옆으로 밀어 고른다
- **로고 버튼**: 지금 색과 비슷한 제품 추천(화면 아래 절반 시트, 카드 2열). 색을 바꾸면 목록도 다시 찾는다
- **추천 기준 = 색 + 질감 + 농도**: 고른 질감 제품을 먼저 보여 주고(2026-11-24), 농도까지 반영한다(2026-11-26). 농도가 바뀌면 입술에 보이는 색이 바뀌므로, 고른 색을 농도만큼 맨입술 쪽으로 옮긴 '보이는 색'(`src/lib/color.js` 의 `lookHex`)으로 찾는다. 처음 농도 80 = 고른 색 그대로, 낮추면 연하고 누드한 쪽, 80 보다 올리면 더 진한 쪽(최대 1.25배). 맨입술 기준색 `BARE_LIP_HEX`(#C68680)은 평균값이다. 새틴·시어·쉬머는 제품 수가 적어 이웃한 농도끼리 같은 목록이 나올 때가 있다
- 제품을 '입술에 발라보기'하면 지금 농도 그대로 바른다
- 추천 카드 (2026-11-24): 사진 · 브랜드 · 제품명 · 가격 / 지금 호수(색 점 + 이름, 길면 한 줄 …) · '호수 보기 N가지 ›' / [입술에 발라보기](회색 #E4E4E7 알약). 누른 카드 **한 장만** 검정 그림자로 떠오르고 버튼이 '지금 바르고 있어요'(`markWorn`, 같은 색 카드가 여러 장이어도 누른 카드만)
- **호수 보기** 화면: 같은 흰 시트 안에서 목록이 왼쪽으로 밀려나고 들어온다. 제품 카드 + 지금 바른 호수 + 호수 동그라미(번호·이름 다 보이게 6열). 누르면 바로 입술에, 뒤로 가면 추천 목록
- 시트 오른쪽 동그라미 버튼은 늘 툭 로고 (2026-11-24)
- 내 톤으로 추천받기는 2026-11-24 삭제(없는 기능)
- 왼쪽 세로 메뉴(스캔·NFC·점 9개·집 알약, "홈 알약")는 2026-11-26 삭제. 처음으로 = 위 로고, 추천 = 가운데 로고 버튼, NFC = 리더기에 대면 바로 바른다

### ① 제품 올리기 — NFC 태그 (`js/nfc.js`, `js/nfc-window.js`)
손님은 이미 실물을 들고 있다는 전제로 만든다.
- **안내 모달** (2026-11-22, Figma 'NFC 버튼 시안' D·F): 홈 4번 화면(`?step=4`)의 NFC 버튼을 누르면(거울 왼쪽 알약의 NFC 버튼은 2026-11-26 삭제) 거울 가운데 세로 상자(640px)에 '제품을 리더기에 대 주세요' + 3단계, 왼쪽 위(닫기 X 와 대칭)에 작은 [테스트] 버튼(2026-11-25, 예전 큰 '다이얼로 고르기 (테스트용)' 버튼 대신). 이 버튼은 **시연·테스트용**으로, 리더기 없이 화면 목록(/api/products)에서 아무 제품이나 골라 태그된 것처럼 '인식했어요' → 제품 카드로 보낸다. 닫기·바깥·Esc 로 닫힌다. 안내 중 등록 안 된 태그를 대면 상자 안에 '?' 를 3.2초 보이고 다시 안내
- **인식했어요 모달** (Figma '제품 인식 후 시안' H): 태그를 읽으면 입술에 바로 바르고, 같은 상자에 제품 사진(흰 테두리·뒤 동그라미 없음)·브랜드·이름을 2.2초 보여 준 뒤(남은 시간은 [입술에 발라보기] 버튼 글자 옆 작은 원이 비워지는 것으로, 2026-11-25 시안 C) **흰 추천 시트의 호수 보기 화면**으로 넘어간다 (2026-11-24, 예전엔 검정 제품 카드). 2026-11-25부터 '인식했어요' 알약·호수/제형/가격 줄·'입술에 바로 발라드릴게요'는 숨김. [입술에 발라보기]·바깥을 누르면 바로 넘어간다. 안내·인식 모달은 반투명(색 없음)
- (예전) 검정 제품 카드 — 거울에서는 2026-11-24부터 쓰지 않음: 사진·브랜드·이름·제형·가격 / "들고 계신 호수를 골라 주세요" + 실제 호수 줄(누를 때마다 입술 색 변경) / [이 색과 비슷한 립 보기] · [가져가기]
- 시작 화면에서 태그해도 거울로 넘어가 바로 바른다
- 등록되지 않은 태그는 작은 '?' 시트가 잠깐 떴다 내려간다
- 태그 → 제품 찾는 순서: ① `NFC_TAGS` 표(태그 번호 UID) ② 태그에 써 둔 제품 ID(`A000…`) ③ 태그에 써 둔 **포장 바코드 번호**(호수까지 찾음)
- 지금 리더기(ACS ACR1555U)는 UID 만 내보내므로 태그는 ① 표에 등록해야 한다. 테스트 카드 3장 등록됨
- **바코드 스캐너는 없는 기능이다.** USB 바코드 스캐너도, 카메라로 바코드 읽기도 쓰지 않는다. 바코드 번호는 ③처럼 NFC 태그 안에 써 둔 경우에만 쓴다
- 시험: 브라우저 콘솔에서 `tookNfc('TEST0001')`

### 호수 고르기 · 가져가기
- 거울에서는 추천 카드의 '호수 보기 N가지 ›' → 같은 시트 안 호수 보기 화면에서 고른다 (위 '거울' 절).
- **가져가기** 시트: 2026-11-24 코드 삭제 (복구는 git 기록, 441f5c9)
- 매장·재고 화면(store-stock.js)은 2026-11-24 삭제

### 자동 초기화 (`js/idle-reset.js`)
- **90초 동안 조작이 없으면** 줄어드는 원 + 남은 초(10초) 안내. 아무 곳이나 누르면 계속, 0초가 되면 고른 색·언어를 모두 지우고 시작 화면으로
- 읽어주기·음성 듣기 중에는 기다린다(최대 60초)
- 기기마다 대기 시간 바꾸기: 그 기기 콘솔에서 `localStorage.setItem('took.idleSeconds', '120')` (10초 이상)
- 직원용 화면은 `<body data-idle-reset="off">`

## 디자인

### 색 (2026-11-20)
- **핑크는 `#FF007B` 한 가지만 쓴다.** 강조 버튼, 손님 말풍선, 진행 점·밑줄 등. 눌렸을 때만 `#D60067`
- 그라데이션·빛 번짐(glow)·유리 테두리를 버튼에 쓰지 않는다. 면은 단색
- 어두운 화면: 바탕 `#0B0B0C` · 면 `#1E1E21` · 눌림 `#2A2A2E` · 선 `#2E2E33` · 흐린 글 `#9B9BA1` · 글 `#FFFFFF`
- 파일 위치: 제품 상세·호수 안내·색상 추천은 `css/took-flat.css` 맨 위 변수(`--f-accent` 등) / 시작 화면·거울은 `css/took-ui.css` 끝 '색 통일' 절 / NFC 시트 `css/took-nfc.css` / 가져가기 `css/took-take.css` / 자동 초기화 `css/wireframe.css` 의 `.idle-keep`
- 2026-11-24 바뀐 것: NFC 안내·인식 모달과 자동꺼짐 화면은 **색 없는 반투명**(각 CSS 맨 아래 '반투명 시안' 블록, 지우면 예전 단색) / 거울 추천 시트는 흰 바탕 · 연회색 카드 · 회색 발라보기 버튼 / 바른 카드는 검정 그림자(빛 번짐이 아니라 그림자)
- 예외(그대로 둠): 거울의 색 다이얼(색 칸·유리 손잡이), 립·제품의 실제 색(카메라 입술·색 견본·질감 동그라미·제품 사진)

### 원본 디자인

- 글꼴 Pretendard

### 화면 틀
- 어떤 기기에서 열어도 `js/device-frame.js` 가 화면을 5:8 틀(`kiosk.html?page=…`) 안으로 옮긴다. 틀은 창 안에 들어가는 가장 큰 5:8 상자를 가운데 두고 남는 곳은 검게 채운다
- 예외: 터치 보정(`calib.html`), PC 미리보기(`preview.html`), 자동 테스트(`navigator.webdriver`)
- 전체화면: 첫 터치 뒤 주소창까지 숨기는 전체화면으로 들어간다. Esc 는 지원 브라우저에서 잠그고, 강제로 풀리면 다음 입력 때 복구한다. 키오스크 PC 는 `scripts/kiosk-chrome.bat` 로 켠다
- 스크롤바는 숨기고 터치·휠 스크롤은 유지한다

## 실행

Node 18 이상.

```bash
npm install            # MediaPipe·ZXing 을 public/vendor 로 복사 + 얼굴 모델 다운로드 (postinstall)
npm start              # http://localhost:3000
npm test               # 단위 테스트 (색 계산·추천·바코드 번호 찾기·터치 보정·호수)
npm run e2e            # Playwright 전체 흐름 테스트 (가짜 카메라)
```

### 빌드
```bash
npm run build:web      # 서버 없는 정적 버전 → dist/static (Vercel 용)
npm run build:static   # 같은 정적 버전, claude.ai Artifact 용
npm run e2e:static     # 정적 버전으로 흐름 테스트
npm run build:apk      # 안드로이드 APK → dist/apk/took.apk (정적 버전 내장 WebView, 음성 인식 없음)
npm run icon:apk       # 앱 아이콘 다시 만들기: android/icon/mark.svg(TOOK 마크, 핑크 #FF007B·검정 바탕) → android/res/
```
- 정적 버전은 `src/lib` 모듈(검색·추천)을 브라우저에서 그대로 돌린다. 페이지 간 값은 sessionStorage(`js/store.js` 의 `go()` / `qs()`)
- Artifact 에서는 카메라가 막혀 있어 샘플 그림·사진 업로드로만 체험된다

| 영어 이름 | `src/data/oliveyoung.global.raw.json` | 글로벌 올리브영 319개 | 영어 버전 |

- **시연용 질감 배정** (2026-11-26 사용자 요청 "가짜여도 되니까 애매한 걸 시어·쉬머에, 이미지가 안 뜨면 안 된다", 같은 날 새틴도): 올리브영 실데이터에는 새틴·시어·쉬머 제품이 거의 없다(새틴 1개·쉬머 0개). 그래서 상품명에 질감 단서가 없던(추정이거나 비어 있던) **실제 제품**을 골라 새틴·시어·쉬머로 배정했다. 이름·사진·가격·호수는 진짜이고 **질감만 시연용**이다(`finish_source: 'demo'`, 카드에 배지 없음). 상품명에 질감이 적힌 제품은 건드리지 않는다. 바꾸려면 `finish-demo.json` 을 고치고 `npm run finish:guess`
  - **빈칸 없음** (같은 날 사용자 요청 "가짜여도 좋으니까 빈칸이 있어선 안돼"): 다이얼 28색 × 질감 5 × 농도 0~100% 모든 조합에서 질감이 맞는 비슷한 색(색차 5 이하) 제품이 나온다(1%마다 14,140칸 확인, 테스트는 10%마다 1,540칸). 제품 하나는 질감이 하나라 근처 제품이 적은 색(주로 농도 50% 넘는 진한 주황·누드)은 다 못 채운다. 그래서 `finish-demo.json` 의 `also` 로 8개 제품을 **원래 질감은 그대로 두고** 다른 질감 목록에도 나오게 했다(레코드의 `finish_also`). 그 목록에서는 찾은 질감으로 보이고(`finish_source: 'demo'`), 발라 보면 거울도 그 질감이다. `also` 는 원래 질감을 안 바꾸므로 상품명에 질감이 적힌 제품에도 붙인다
- 그전(11-24)에 만든 사진 없는 가짜 질감 제품 84개(`products.texture-demo.json`)는 2026-11-26 모두 삭제. 거울 추천에는 이제 사진 없는 제품이 나오지 않는다 (만들던 `scripts/make-texture-demo.js` 는 안 쓰는 채로 남겨 둠)

- **지어내지 않는다**: 수집하지 않은 정보(바코드·색 이름·설명 등)는 비워 두고 '정보 없음'으로 보인다. 색 계열·제형은 색값·상품명으로 **추정**한 값이며 화면에 그렇게 표시한다
- 호수 이름·바코드는 올리브영 옵션 목록, 색상값은 색 칩 사진에서 뽑은 추정값(`color_source`). 칩 사진을 쓸 수 없는 호수는 빼고 `skipped` 에 적는다
- 호수가 없는 제품은 거울 화면 목록(추천·검색)에서 뺀다(`src/lib/catalog.js`). ID·바코드로 찾기는 된다
- 영어로 답할 때는 영어 이름이 있는 제품 안에서만 추천한다. 이름을 지어내지 않는다
- 대표 이미지는 `public/images/lip-tints` (크롤링 폴더에서 복사)

### 시연용 표시 · 실데이터만 보기
- 판단은 `src/lib/catalog.js` 의 `isDemo(제품)` 하나: `source` 가 `oliveyoung` 이 아니면 시연용이다
- 화면 표시는 `public/js/demo.js` 의 `demoBadge()` 하나(무채색 테두리 '시연용' / 'Demo'). 제품 카드·호수 안내·가져가기·매장 재고 창에 붙는다
- **실데이터만 보기**: 아무 화면 주소에 `?real=1` 을 붙여 한 번 열면 그 기기에서 계속 켜진다(`localStorage['took.realOnly']`), `?real=0` 으로 끈다. 켜면 시연용 제품·호수가 추천·검색·바코드·이름 찾기에서 빠지고 매장 재고 칸·버튼도 숨는다
- 서버 전체로 켜려면 환경변수 `TOOK_REAL_ONLY=1`. 화면은 요청마다 `X-Took-Real-Only: 1` 머리말로 알린다


- 호수가 있는 제품은 가장 가까운 호수로 보여 준다
