## 3. 부스 당일 준비 순서 (갤럭시탭)

1. **앱 설치**: `took/dist/apk/took.apk` 를 갤탭에 옮겨 설치 (출처를 알 수 없는 앱 허용 필요). 이미 깔려 있으면 덮어 설치
2. **USB 웹캠 연결**: 허브 → 갤탭. 처음 열 때 '카메라 권한' → 'USB 기기 접근 허용' 창이 차례로 뜨면 둘 다 허용
   - 안 잡히면: 시작 화면 5초 길게 누르기 → 관리자 → **웹캠 연결 설정** 에서 카메라 고르기·'모든 카메라 시험'
3. **NFC 리더기**: ACR1555U 전원 켜고 갤탭과 블루투스 연결(키보드로 잡힘). 관리자 → **NFC 테스트** 에서 카드를 대 보고 번호가 찍히는지 확인
   - 리더기는 60초 동작 없으면 잠듭니다. 시연 중 안 읽히면 버튼 눌러 깨우기
4. **시간 표시 확인**: 2026-11-29부터 **기본 꺼짐**입니다. 관리자 '기능 점검' 줄 오른쪽이 `시간 표시 꺼짐` 인지만 확인 (전에 직접 켜 둔 기기라면 눌러서 끄기)
5. **(필요하면) 터치 보정**: 거울 유리 위 터치 필름이 어긋나면 관리자 → 터치 범위 조정 → 정확도 테스트(오차 30px 이하면 성공)
6. **화면 고정 켜기**: 관리자 제목 줄 '화면 고정 켜기' → 시스템 확인. 홈·최근 앱이 막힙니다
   - 풀기: 같은 버튼, 또는 **뒤로 + 최근 앱 버튼을 함께 길게**. 기기를 껐다 켜도 풀립니다
7. '스마트 미러로 돌아가기' → 시작 화면에서 한 바퀴 시연해 보기 (태그 → 바르기 → 자세히 보기 → 90초 뒤 처음 화면으로)

관리자 화면 여는 법: **시작 화면을 5초 길게 누르기**

## 4. 시연 중 자주 생길 일

| 증상 | 할 일 |
|---|---|
| 거울이 검은 화면 / 카메라 안 나옴 | 웹캠 USB 다시 꽂기 → 앱 다시 열기. 화면 고정 중이면 앱이 고정을 잠깐 풀고 허용 창을 띄운 뒤 다시 겁니다(확인 창 한 번 더 뜸) |
| 거울이 끊겨 보임 | 시간 표시를 켜서 `합계` 가 33ms 를 넘는지, `입술 찾기` 옆이 `CPU` 인지 확인. 조명을 밝게, 얼굴 1명 정면 |
| NFC 태그를 대도 반응 없음 | 리더기가 잠들었거나 블루투스 끊김. 등록 안 된 태그면 화면에 '?' 가 잠깐 뜹니다 |
| 입술 색이 실제와 다르게 보임 | 조명 영향. 관리자 → 카메라 색 보정 (컬러체커 흰 칸) |
| 손님이 떠난 뒤 화면이 그대로 | 90초 지나면 자동으로 처음 화면 + 한국어로 돌아갑니다 |

## 5. NFC 태그 등록

- 리더기는 태그 번호(UID)만 보내므로 **`public/js/nfc.js` 의 `NFC_TAGS` 표**에 `'태그번호': '제품ID'` 를 적어야 합니다.
- 지금 등록: 시험용 `TEST0001~0006` + 실물 테스트 카드 3장.
  - 카드 1·3번은 메모에서 글자가 빠진 11글자로 적혀 있습니다(부분 일치로 인식은 됨). 관리자 → NFC 테스트에서 다시 대 보고 나온 **14글자**로 바꿔 두면 가장 확실합니다.
- 제품 ID(`OY-A000…`)는 `src/data/products.oliveyoung.json` 에서 제품명으로 검색해 찾습니다.
- 표를 고친 뒤에는 **APK 를 다시 빌드**해야 앱에 반영됩니다 (6번).
- 리더기 없이 시험: 브라우저 콘솔에서 `tookNfc('TEST0001')`

## 6. 빌드 · 배포 명령

모두 `took\took` 폴더에서. Node 18 이상.

| 하고 싶은 것 | 명령 | 결과 |
|---|---|---|
| 내 컴퓨터에서 켜 보기 | `npm start` | http://localhost:3000 |
| 계산이 안 깨졌는지 확인 | `npm test` | `# fail 0` 이면 정상 |
| 앱(APK) 다시 만들기 | `npm run build:apk` | `dist/apk/took.apk` (이 PC 의 Android SDK·NDK r27c 필요, 이 컴퓨터에 설치돼 있음) |
| 웹(Vercel) 올리기 | `git push origin touch-calibration:main` | 1~2분 뒤 자동 반영 |
| 서버(Render) 올리기 | Render 대시보드 → Manual Deploy | https://took-y6rn.onrender.com (무료라 15분 쉬면 잠들고 깨는 데 약 50초) |

- **웹을 고친 뒤 부스 앱에 반영하려면 반드시 `npm run build:apk` 를 다시** 하고 갤탭에 재설치합니다. 앱은 웹 주소를 여는 게 아니라 안에 화면을 담고 있습니다.
- 앱 안의 설정값(터치 보정·시간 표시 등)은 Chrome 과 따로 저장됩니다. 앱을 지우고 다시 깔면 초기화됩니다.
- Render 는 '카드 담기'(휴대폰 `basket.html`) 기능에만 필요합니다. 부스 기본 흐름(거울·NFC·다이얼)은 서버 없이 돕니다.
