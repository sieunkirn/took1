# 직접 고치기 안내서

Claude 없이, 또는 사용량을 아끼면서 자주 바꾸는 곳을 직접 고칠 때 보는 문서입니다.
줄 번호는 코드를 고치면 금방 바뀌어서, **파일 안에서 검색할 글자(검색어)** 로 적었습니다. VS Code 나 메모장에서 파일을 열고 `Ctrl+F` 로 검색어를 찾으세요.

- 처음 만든 날: 2026-11-24 (앞으로 화면이 바뀌면 이 문서도 같이 고칩니다)
- 파일 위치는 모두 `took/` 폴더 기준입니다. 화면 코드는 `public/` 안에 있습니다

## 0. 고치기 전에 꼭

### 내 컴퓨터에서 켜 보기
```powershell
cd "C:\Users\kgwan\OneDrive\바탕 화면\took\took"
npm start
```
브라우저에서 `http://localhost:3000` 을 엽니다. 파일을 고친 뒤에는 `Ctrl+Shift+R`(강력 새로고침)로 다시 엽니다.

### 고친 뒤 확인
```powershell
npm test
```
`# fail 0` 이 나오면 기본 계산(색·추천·호수 등)은 안 깨진 것입니다. 화면 모양은 브라우저에서 직접 봐야 합니다.

### 망가졌을 때 되돌리기 (git)
```powershell
git status
```
바꾼 파일 목록이 나옵니다. 파일 하나를 마지막으로 저장(커밋)한 상태로 되돌리려면:
```powershell
git checkout -- public/css/took-ui.css
```
(파일 이름만 바꿔서 씁니다. 커밋하지 않은 수정은 사라지니 조심하세요.)

### 지켜야 할 규칙 (README·CLAUDE.md 에 있는 것 중 자주 걸리는 것)
- **거울 첫 화면은 맨입술.** 시작 화면이나 초기화 뒤 거울에 들어오면 아무 색도 입히지 않습니다. `public/js/palette.js` 의 `bareStart` · `isBare` 부분은 함부로 지우지 마세요
- **핑크는 `#FF007B` 하나.** 눌렸을 때만 `#D60067`. 그라데이션·빛 번짐(glow)은 쓰지 않습니다
- 등록되지 않은 제품 정보(바코드·색 이름 등)를 지어내지 않습니다

**화면 고정 (2026-11-26, 안드로이드 앱에서만)** — 제목 줄의 `화면 고정 켜기` 를 누르면 안드로이드가 "앱을 고정할까요?" 창을 띄우고, 확인하면 홈·최근 앱·알림 창이 막힙니다. 끌 때는 같은 자리의 `화면 고정 끄기`(검은 알약), 또는 뒤로 + 최근 앱 버튼을 함께 길게 누릅니다. 고정 중에는 뒤로가기 버튼도 듣지 않습니다. 기기를 껐다 켜면 풀리니 다시 켭니다. 고정 중에 웹캠 허용 창이 필요해지면(웹캠을 뽑았다 꽂았을 때 등) 앱이 고정을 잠깐 풀고 허용 창을 띄운 뒤, 허용을 누르면 "앱을 고정할까요?" 창을 다시 띄웁니다. 웹(Chrome)에서는 할 수 있는 일이 없어 버튼이 나오지 않습니다. 앱 쪽 코드는 `android/src/com/took/kiosk/MainActivity.java` 의 `KioskBridge` 이고, 고친 뒤에는 `npm run build:apk` 로 앱을 다시 만들어야 합니다.
